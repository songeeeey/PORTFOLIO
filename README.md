- 📅 **기간:** 2025.10 ~ 2025.12 (52일)
- 👥 **인원:** 6명

**📌 담당 역할**
- 파인튜닝용 합성 텍스트 데이터 2,621건 설계 및 생성
- 형식/의미/중복 3단계 검증 파이프라인 직접 구축 → 최종 2,493건 정제

**핵심 성과**
- 모델 신뢰도 1/5 → 5/5 달성, GPTScore 약 6배 향상
- 처리 속도 249초 → 167초 (33% 단축)

**기술 스택:** `Python` `LangChain` `MySQL` `HuggingFace`
